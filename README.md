# 🍎 Apple Website Clone

A responsive clone of Apple's official website built with HTML5, CSS3, and Bootstrap.

🔗 **Live Demo:** https://Adarshediga8.github.io/apple-website-clone/

### 🚀 Tech Stack
- HTML5
- CSS3
- Bootstrap 5
- Responsive Design

### ✨ Features
- Apple-style navbar & hero section
- iPhone 17 Pro showcase
- Fully responsive for mobile & desktop
- Clean & modern UI
